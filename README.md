# Asadito

Organiza un asado sin caos:

- Lista colaborativa de compras
- Invitaciones por link
- Gastos compartidos
- Todo en tiempo real

## MVP

- Login por código (email)
- Crear evento
- Checklist por categorías
- Invitación por link
- Registro de gastos

## Tech

- React + Vite + TypeScript
- Supabase (Auth, DB, Realtime)
- PWA / Store-ready
